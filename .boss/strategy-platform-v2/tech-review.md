# 策略平台 V2 技术复核

## 摘要

- 已有实现覆盖核心实体/API，但原“方案与实现同步”状态遗漏了权限、未来数据、客户端和恢复验收问题。
- 阻断项已修复并有行为回归：迁移擅自授权、草案终态复活、私有提案代发、ML 补历史泄露未来、CSRF 未接通、备份错误重试/幂等、MySQL 外键恢复/删账号。
- 维持 Flask 模块化单体、旧策略接口和数据库权威；没有引入在线任意代码执行、消息队列或云平台迁移。
- 结论：核心实现通过隔离验收；生产配置/真实 GitHub/签名发布/开奖周期观察尚待上线环境验证。

## 问题闭环

| 风险 | 修复与证据 |
| --- | --- |
| 未受邀账号启动后加入工作区 | 只镜像现有 active membership；移除成员不复活；重跑测试 |
| owner 越权发布私有提案、重复发布 | 原作者权限、7 天有效期、终态保护、条件状态更新、confirm/expected_revision |
| 回测加载未来 DB 数据 | 所有 V2 runner 携带 cutoff；回测/结算共用 evaluator；逐期 cutoff 断言 |
| 生肖 clone 与原策略不同 | 调用已登记原算法，不替换为简单遗漏排序 |
| 旧通知借用同一期其它结果 | 优先原记录保存快照，不凭期号拼接无关联运行 |
| 网页/移动端 CSRF 403 | 真实 meta 检测和共享会话 token；真实浏览器/移动登录→V2 写入测试 |
| GitHub 限流永久失败、任意 422 被判成功 | pending 退避、远端内容比较、不可变 payload、逐条提交释放写锁 |
| 本地恢复/归档缺失 | digest/Schema/引擎校验、草稿预览确认、tombstone；不导出用户/对话/凭据 |
| SQLite 通过而真实库外键失败 | 恢复按依赖 flush；保留期/删账号先解关联；MariaDB 40 项通过 |
| Flutter 不能编译/目录过期 | 修重名与 nullable；过滤 draft/地区/权限；刷新撤权与多工作区；4 项行为测试 |
| 普通分支误发布 APK | 验证与 Release 分离；tag/manual 才签名上传；Docker 依赖验证 |

已知维护债务：原 Flutter 非策略页面仍有 warning/info lint，CI 展示但不将其升级为错误；既有 Query.get 使用产生 SQLAlchemy deprecation warning。它们没有被全局禁用。

## 独立聊天页补充

用户原消息对应的真实供应商回复为客户端类型限制，并非策略反馈。独立页将服务错误与助手正文区分，保持历史可恢复；新的会话 API 仍仅本人和对应工作区可访问。后续请求包含最新有效草案，避免多轮讨论丢失参数；新策略发布后绑定原会话。79 项测试与浏览器主路径通过，真实供应商恢复仍依赖管理员选择兼容 API。
